# sales-website-landing
Responsive sales landing page website for Nexora.

## Included
- Modern black, white, and electric blue landing page
- Premium hero, feature, testimonial, pricing, FAQ, and contact sections
- Responsive mobile-friendly layout
- Interactive FAQ and smooth reveal animations

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Project structure
- `index.html` – page layout
- `styles.css` – design and responsive styling
- `script.js` – interaction logic
